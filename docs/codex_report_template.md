# Codex Report Template

Use this exact structure at the end of Codex implementation tasks.

## Codex Report

### 1. Prompt executed

Briefly summarize the task that was followed.

### 2. Changed files committed

List every file committed.

### 3. What was implemented

Briefly explain what changed.

### 4. Tests/checks performed

List commands and results.

### 5. Commit and push result

Include commit hash, push result, and final git status.

### 6. What was consciously not implemented

List excluded features, refactors, or scope items.

### 7. Risks / limitations

Briefly state any remaining risks or limitations.

### 8. Next recommended Codex block

Suggest the next small block, but do not implement it.
